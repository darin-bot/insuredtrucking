# New Authority Handbook PDF Required

## File Needed
Place the New Authority Insurance Handbook PDF at:
```
public/new-authority-insurance-handbook.pdf
```

## Purpose
This PDF is downloaded when visitors complete the email gate on the New Authority Insurance page.

## Lead Alert Flow
1. Visitor enters email (and optional name) in the HandbookDownloadModal
2. Form POSTs to FormSubmit AJAX endpoint: `https://formsubmit.co/ajax/darin@insuredtrucking.com`
3. If FormSubmit returns `success: true`, the PDF downloads to the visitor's browser
4. Darin receives a lead alert email at darin@insuredtrucking.com with the visitor's information

## FormSubmit Configuration Notes
- The form uses `_captcha: false` parameter
- This requires the FormSubmit form for darin@insuredtrucking.com to be activated and configured to allow captcha bypass
- If FormSubmit is not activated, visitors will see an error message with instructions
- Darin may need to confirm the email address with FormSubmit on first use
